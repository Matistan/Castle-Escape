This project uses Unity version 1000.3.10f1

how to start working on it:

1. open terminal
2. go into where you want this project to be cloned into
3. `git clone https://github.com/Matistan/Castle-Escape.git`
4. `cd "Castle Escape"`
5. `git lfs pull` (you must have git lfs installed)
6. open Unity Hub
7. Click the Add button and select "Add project from disk"
8. Navigate to the cloned folder, and click open
9. Open the project and start working
